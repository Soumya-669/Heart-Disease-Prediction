# ❤️ AI-Powered Heart Disease Prediction System

An advanced Machine Learning based healthcare application that predicts the likelihood of heart disease using patient medical data.

---

## 🚀 Features

- AI-powered prediction system
- Interactive healthcare dashboard
- Real-time heart risk analysis
- Modern UI with Streamlit
- Risk visualization using charts
- Responsive and attractive frontend

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- Plotly
- Joblib

---

## 📊 Machine Learning Model

This project uses the **K-Nearest Neighbors (KNN)** algorithm for prediction.

### Model Workflow
1. Data preprocessing
2. Feature scaling
3. Model training
4. Prediction generation
5. Risk visualization

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Soumya-669/Heart-Disease-Prediction.git
```

Move into project folder:

```bash
cd Heart-Disease-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
